# Tests and Results

## Test results
Scores for objective tests are shown immediately after submission. The All-India rank for scheduled tests is published 48 hours after the test window closes.

## Reattempting tests
A test can be reattempted in practice mode after the first attempt, but only the first attempt counts towards the rank.

## Reporting a wrong question or answer key
If a question or answer key seems incorrect, the student should use the "Report Question" option in the test solution screen. Reported questions are reviewed by the academic team within 72 hours, and scores are revised if the report is accepted.
