# Live Classes

## Joining a live class
The link to join a live class appears in the batch section of the app 10 minutes before the class starts. Students receive a notification when the class goes live.

## Missed classes and recordings
Recordings of live classes are uploaded to the batch within 6 hours of the class ending, so students who miss a class can watch it later.

## Class schedule changes
Any change in the class schedule is announced in the batch timetable and through app notifications at least 12 hours in advance.
